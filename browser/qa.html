Q&A

How do I read the Stokes channels in an OpenEXR file?

Each OpenEXR file stores four RGB Stokes layers (S0–S3, 12 channels) plus standard R, G, and B channels that duplicate S0 so regular RGB viewers display the intensity image (15 floating-point channels in total).

Channels follow the naming pattern Sn.band (for example, S1.G is the s1 component in the green band). To read the green-band Stokes vector, select (S0.G, S1.G, S2.G, S3.G).

What is the difference between the θφ and Duff maps?

Both maps store the same measured polarization at every pixel. Because a Stokes vector is defined relative to a local reference frame perpendicular to the light ray, the two formats differ only in how they choose that frame.

θφ (thetaphi). Defines the tangent basis from the spherical coordinates (θ, φ) (Yi et al., 2024). This frame has singularities at the north and south poles, but varies smoothly elsewhere, so we use it for visualizing environment maps in the paper.

Duff. Constructs an orthonormal basis directly from the ray direction (Duff et al., 2017). It introduces discontinuities along the seam where the sign branch switches, but matches Mitsuba 3’s default polarization frame, so we distribute this format for direct use with our penvmap rendering plugin.

You can convert between θφ, Duff, or any other frame convention by rotating the local basis around each ray with a rotation Mueller matrix. Rotating the frame by an angle ϑ rotates (s1, s2) by 2ϑ, while intensity (s0) and circular polarization (s3) remain unchanged.

S2L2. On Hugging Face, we also distribute the frame-free S2L2 representation (Yi et al., 2025), which encodes linear polarization orientation without choosing a local frame. Each ray can be converted between S2L2 and either the θφ or Duff Stokes frames.

Why did we add Linear Stokes maps?

We added Linear Stokes maps to provide more accurate outdoor color reproduction. As noted in the paper and supplementary material, our Full Stokes camera picks up near-infrared (NIR) light in the red channel. Adding an NIR-cut filter improved color fidelity near the image center, but it also altered the polarization measurements, so we captured the Full Stokes maps without one.

To complement them, we later captured additional environment maps using a Sony IMX250MYR color polarization camera. Each Linear Stokes map records RGB intensity (s0) and linear polarization (s1, s2), but does not include circular polarization (s3).
