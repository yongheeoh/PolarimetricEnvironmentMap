# Project page

Website for **Real-world Polarimetric Environment Map Dataset**, SIGGRAPH Asia 2026.

[Live page](https://yongheeoh.github.io/PolarimetricEnvironmentMap/)

- `static/`: figures, videos, styles and scripts.
